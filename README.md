# JF Diseños 3D

Experiencia interactiva de audio y video 3D para **JF Diseños 3D**.

## Demo

[Ver demo en vivo](https://tu-usuario.github.io/jf-disenos-3d/)

## Descripción

Showcase interactivo que presenta la historia de JF Diseños 3D a través de 5 escenas con:

- Audio inmersivo con narración por escena
- Efectos visuales 3D con Three.js
- Animaciones de partículas, glitch y portales
- Subtítulos sincronizados
- Diseño responsive para mobile y desktop

## Tecnologías

- **HTML5** - Estructura
- **CSS3** - Estilos y animaciones
- **JavaScript** - Lógica de escenas y transiciones
- **Three.js** - Renderizado 3D y efectos post-processing

## Estructura


## Uso

1. Abrir `index.html` en un navegador
2. Hacer clic en la pantalla de inicio
3. Disfrutar de la experiencia
