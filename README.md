# JF Diseños 3D

Experiencia interactiva de audio y video 3D para **JF Diseños 3D**.

## Demo

[Ver demo en vivo](https://tu-usuario.github.io/jf-disenos-3d/)

## Descripción

Proyecto que incluye una experiencia interactiva de 5 escenas con Three.js y un showcase de video con React.

## Estructura

```
├── index.html              # Experiencia principal (Three.js + 5 escenas)
├── showcase/
│   └── index.html          # Showcase de video con React
├── musica/
│   ├── tema.mp3            # Música de fondo
│   ├── Ecena 1-5.mp3       # Audio por escena
│   ├── jf.png              # Logo
│   └── logo-website.png    # Favicon
└── README.md
```

## Tecnologías

- **HTML5** - Estructura
- **CSS3** - Estilos y animaciones
- **JavaScript** - Lógica de escenas y transiciones
- **Three.js** - Renderizado 3D y efectos post-processing
- **React 18** - Showcase de video (via CDN)

## Uso

### Experiencia Principal
1. Abrir `index.html` en un navegador
2. Hacer clic en la pantalla de inicio
3. Disfrutar de la experiencia de 5 escenas

### Showcase de Video
1. Abrir `showcase/index.html` en un navegador
2. El video se reproduce con el texto "Descubrí tu mundo, Creá tu destino"
3. A partir del minuto 1:31 aparece el botón "Ir a Tienda"
